Image Morphing Application

A sophisticated Java desktop application using Swing that creates smooth morphing sequences between two PPM images. Project 2

Network Performance in Distributed Systems

Academic research exploring the relationship between network latency and consistency in replicated databases. Uses Docker containers running Redis primary-replica architecture to measure stale read rates, version lag, and time-to-consistency across different write intervals. Demonstrates how low-latency environments achieve perfect consistency with 0% stale reads.
